# v7 后端服务器接口

> 供子服务器插件对接代理使用。后端服务器通过「访问令牌」鉴权后，可把封禁/解封/踢出/广播/转移/查询等操作委托给代理统一处理。

## 1. 概念与鉴权

- 后端服务器（子服务器）在代理侧以 `ServerList` 表（`server_list`）保存鉴权记录，通过 `uid` 关联到 `proxy.backend.servers`（JSON 配置）里的 `BackendServer.uid`。
- 服务端只保存令牌的 **SHA-256 哈希**；原始令牌仅在「创建/重置」时返回一次，请立即保存。
- v7 接口鉴权头（**无需** `Event` 头，也**不在** `AuthenticateCheck` 拦截器范围内）：

```
Authorization: Bearer <token>
```

- 令牌格式：`ny_` + 48 位随机字母数字（例：`ny_AbC...`）。

## 2. 管理面板（V3）——凭据增删改查

> 这些接口走 V3 鉴权（`Authorization: Bearer <RSA 加密 accessToken>` + `Event` 头），且需要 `minecraftproxy.admin`（`PROXY_ADMIN`）权限。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/zako/v3/proxy/serverlist` | 列出所有凭据（不含令牌） |
| POST | `/api/zako/v3/proxy/serverlist` | 创建凭据（返回一次性令牌） |
| PUT | `/api/zako/v3/proxy/serverlist/{uid}` | 更新（改名 / 启停 / 重置令牌） |
| DELETE | `/api/zako/v3/proxy/serverlist/{uid}` | 删除凭据 |

**创建请求体**（POST，`uid` 必填，需已存在于子服务器配置）：

```json
{ "uid": "lobby-001", "serverName": "大厅服" }
```

**创建/重置响应**（`token` 只在这一次出现）：

```json
{
  "uid": "lobby-001",
  "serverName": "大厅服",
  "enabled": true,
  "createdAt": "2025-09-06T02:00:00",
  "lastUsedAt": null,
  "createdBy": "管理员uid",
  "token": "ny_xxxxxxxx...",
  "note": "token 只显示这一次，请立即保存"
}
```

**更新请求体**（PUT，字段均可选）：

```json
{ "serverName": "新名字", "enabled": false, "regenerate": true }
```

## 3. v7 后端操作接口

> 基路径：`/api/v7/backend`。鉴权：`Authorization: Bearer <token>`。校验失败返回 `401`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v7/backend/servers` | 子服务器列表（在线状态/人数/玩家） |
| GET | `/api/v7/backend/players` | 在线玩家快照 |
| POST | `/api/v7/backend/players/ban` | 按 Minecraft UUID 封禁 |
| POST | `/api/v7/backend/players/unban` | 按 Minecraft UUID 解封 |
| POST | `/api/v7/backend/players/kick` | 踢出在线玩家 |
| POST | `/api/v7/backend/players/transfer` | 转移玩家到其他子服务器 |
| POST | `/api/v7/backend/broadcast` | 向所有在线玩家广播 |

### 封禁（POST `/players/ban`）

```json
{
  "uuid": "069a79f444e94726a5befca90e38aaf5",
  "reason": "使用外挂",
  "type": 20,
  "expire": "2025-10-01T00:00:00"
}
```

- `uuid` 必填（带不带连字符均可），服务端会反查：Yggdrasil 玩家 → 按 NyanID UID 封禁；正版玩家 → 按 Mojang UUID 封禁。
- `type` 可选，缺省 `20`（游戏封禁）；支持 `6`（死封）。
- `expire` 可选，ISO-8601；缺省永久。
- 响应示例：

```json
{
  "message": "Banned",
  "banId": "0000000000001",
  "target": "069a79f444e94726a5befca90e38aaf5",
  "targetType": 1,
  "type": 20,
  "expireTime": "2025-10-01T00:00:00",
  "timestamp": "2025-09-06T02:00:00"
}
```

### 解封（POST `/players/unban`）

```json
{ "uuid": "069a79f444e94726a5befca90e38aaf5" }
```

解除该目标所有生效封禁，返回 `affected` 数量。

### 踢出（POST `/players/kick`）

```json
{ "player": "玩家名或UUID", "reason": "原因(可选)" }
```

### 转移（POST `/players/transfer`）

```json
{ "player": "玩家名或UUID", "targetServer": "目标服务器名或uid" }
```

### 广播（POST `/broadcast`）

```json
{ "message": "服务器将在 5 分钟后重启" }
```

消息非空、长度 ≤ 512，返回 `recipients`（收到人数）。

## 4. 注意事项

- `token` 只显示一次；忘记令牌请在管理面板用 `regenerate: true` 重置。
- 停用某个后端服务器：PUT 设 `enabled: false`，其 v7 请求将立即返回 401。
- 令牌哈希使用 SHA-256（高熵随机令牌，无需 PBKDF2 盐化）；查询走唯一索引。
- v7 接口**不经过** `AuthenticateCheck`，完全依赖 `ServerList` 令牌鉴权，请妥善保管令牌。
