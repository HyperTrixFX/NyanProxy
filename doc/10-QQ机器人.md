# QQ 机器人（Qbot）

项目内置一个 QQ 机器人，通过 `io.github.kloping.qqbot` 框架接入 QQ，可在私聊/群聊里查看服务器状态、
在线玩家、绑定 NyanID、查看个人长期记忆、玩小游戏，以及和 AI 聊天。

## 配置

在 `config/application.yml` 的 `NyanidSetting.Qbot` 下：

```yaml
NyanidSetting:
  Qbot:
    isEnable: false       # 是否启用 QQ 机器人
    appid: "..."          # 机器人 appid
    secret: "..."         # 机器人密钥
```

`isEnable=false` 时启动日志会提示「Qbot已在配置文件中被关闭」。

## 工作流程

1. `QbotServices.initQbot()`（`@PostConstruct`）在启用时创建 `Starter` 并注册 `ListenerHost`。
2. 好友消息 / 群消息通过 `@EventReceiver` 监听，转成内部事件
   `QbotFriendMessageReceivedEvent` / `QbotGroupMessageReceivedEvent`，`postAsync` 到内部 `EventBus`。
3. `QbotListener` 从 QQ metadata 中提取 `author.union_openid`，整理为
   `QbotMessageContext`，交给 `QbotCommandService`。
4. `QbotCommandService` 统一做命令解析、权限判断、冷却、参数校验和回复；
   所有长回复由 `QbotTextSender` 按长度拆分后再发送。

> **身份约定**：长期记忆与绑定都以 `author.union_openid` 为唯一键。代码不会把
> `member_openid` / `user_openid` 写进长期记忆，避免同一用户在不同群/单聊中产生分裂的记忆。
> 如果某条事件确实没有 `union_openid`，机器人会记录错误并回复“暂时认不出你”，而不是静默写入错误数据。

## 绑定 NyanID（仅私聊）

绑定用于让机器人识别“你是哪个 NyanID 账号”，也是使用 `/bc`、`get_my_profile`、
`get_my_ban_status`、`get_my_tickets` 等敏感查询的前提。

1. 私聊机器人发送 `/bind 你的邮箱`；
2. 系统向该邮箱发送 **6 位验证码**，5 分钟内有效；
3. 私聊发送 `/bind 验证码`（也支持 `/bind verify 验证码`）完成绑定；
4. 解绑：`/unbind`，然后在 60 秒内发送 `/unbind confirm`。

规则：

- 一个 QQ 只能绑定一个 NyanID；一个 NyanID 也只能绑定一个 QQ。
- 同一 QQ 60 秒内只能重发一次验证码；同一邮箱 60 秒内也只发一次；同一验证码最多尝试 5 次。
- 群聊发送 `/bind` / `/unbind` 只会提示去私聊，不会在群里暴露邮箱或验证码。
- 解绑不会自动删除长期记忆；要删除记忆请使用 `/forget`。
- 绑定只证明邮箱归属，不改变 NyanID 账号本身的密码/2FA/权限。

## 固定指令

好友 / 群聊通用：

| 指令 | 说明 |
| --- | --- |
| `/help` | 指令列表 |
| `/status` | 各子服务器在线状态与人数 |
| `/list`（`/online`） | 当前在线玩家及所在子服务器 |
| `/ping` | 确认机器人在线 |
| `/game` | 小游戏菜单 |
| `/memory` | 查看当前 QQ 的长期记忆条数与最近记忆 |
| `/forget` | 忘记当前 QQ 的聊天缓存与全部长期记忆（需 `/forget confirm`） |
| `/bind 邮箱` / `/bind 验证码` | 绑定 NyanID（仅私聊） |
| `/unbind` | 解绑（仅私聊，需 `/unbind confirm`） |
| `/bc 消息` | 全服广播（需已绑定且拥有管理员权限） |
| `/nyanid` / `d` | 保留的彩蛋回复 |

> 不需要 `/ai` 指令：直接发普通消息就会走 AI；任何固定指令都匹配不上的内容也会自动交给 AI。

## 小游戏

| 指令 | 玩法 | AI 依赖 |
| --- | --- | --- |
| `/guess` | 猜 1~100 的数字，8 次机会；`/guess 数字` 提交 | 无 |
| `/rps 石头\|剪刀\|布` | 猜拳 | 无 |
| `/roll 2d6` | 掷骰子，默认 `1d6`；最多 10 颗、100 面 | 无 |
| `/quiz` + `/answer A-D` | 本地题库问答 | 无 |
| `/story` / `/story 想法` | 故事接龙 | AI 可选；AI 不可用时用固定剧情继续 |
| `/fortune` | 今日运势（按 QQ + 日期稳定生成） | 无 |
| `/giveup` | 放弃当前游戏 | 无 |

游戏状态按 `union_openid` 隔离，10 分钟无操作自动过期。除故事接龙外，所有游戏都不依赖 AI；
即使 `ai.enable=false`，猜数字、猜拳、骰子、问答、运势仍可正常使用。`ai.enable=false` 时
AI 聊天会返回洛橘口吻的提示，记忆提取任务不运行，故事接龙退回固定剧情；固定指令、绑定和本地游戏不受影响。

## `/bc` 广播权限

`/bc` 是写操作，必须同时满足：

1. 当前 QQ 已通过 `/bind` 绑定 NyanID；
2. 绑定账号拥有以下任一权限节点：
   - `*`
   - `minecraftproxy.admin`
   - `minecraftproxy.command.broadcast`
   - `nyanid.admin.cctop`

未绑定或没有权限时不会执行广播；内容还会经过长度限制（200 字）与敏感词检查。
