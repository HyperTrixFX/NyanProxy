# 配置参考

配置分为两类：

1. **静态配置**：`config/application.yml`（Spring 环境变量、数据源、Yggdrasil、AI 等）。
2. **动态配置**：数据库 `SystemConfig` 表（`key` → `value`），主要是代理的 `proxy.*` 项。修改后可热重载（`ReloadConfig` 控制台命令 / 重启）。

## 1. 静态配置（application.yml）

### 数据源 / Redis / 邮件

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/awaa1111?...
    username: ...
    password: ...
  data:
    redis:
      host: localhost
      port: 6379
      password: ...
  mail:
    host: smtp.qq.com
    port: 587
    username: ...
    password: ...
```

### 服务器

```yaml
server:
  port: 8081          # HTTP 端口
  address: localhost
```

### NyanidSetting（业务开关）

```yaml
NyanidSetting:
  EnableProxy: true          # 是否启动 Minecraft 代理
  EnableCommand: true        # 是否启用控制台命令
  EnableUserRegister: true   # 是否允许注册
  allowedOriginPatterns: "http://**:*"   # CORS
  MAX_REQUESTS_PER_SECOND: 5              # authserver IP 限流
  TIME_FRAME_IN_MILLISECONDS: 9500
  HOST: "http://localhost:2095"           # 前端域名（注册邮件链接）
  TurnstileSecretKey: ...
  TurnstileSecretSiteKey: ...
  Qbot:                       # QQ 机器人（见 doc/10）
    isEnable: false
    appid: "..."
    secret: "..."
```

### Yggdrasil（外置登录）

```yaml
yggdrasil:
  serverName: "..."          # 元信息
  implementationName: "..."
  implementationVersion: "..."
  links-homepage: "http://127.0.0.1:2095/"
  links-register: "http://127.0.0.1:2095/#/register"
  feature-non_email_login: true
  SkinDomains: "localhost"
  APILocation: "http://localhost:8081"   # 纹理地址前缀
  publicKey: |   # RSA 公钥（客户端用）
  privateKey: |  # RSA 私钥（服务端解密/签名用）
```

### AI

```yaml
ai:
  provider: ollama   # ollama 或 deepseek
  enable: true
ollama:
  url: http://localhost:11434/api/chat
  model: qwen3.5:9b

  url: https://api.deepseek.com/chat/completions
```

## 2. 动态配置（SystemConfig 表）

### proxy.port

代理监听端口，默认 `25565`。

### proxy.backend.servers（子服务器列表）

JSON 字符串：

```json
{
  "default_server": "lobby",
  "server_list": [
    { "uid": "lobby-001", "priority": 1, "name": "lobby", "host": "localhost", "port": 25566 },
    { "uid": "survival-001", "priority": 2, "name": "survival", "host": "localhost", "port": 25567 }
  ]
}
```

- 字段：`uid`（唯一标识）、`priority`（排序）、`name`（显示名）、`host`、`port`。
- 兼容旧版 JSON 数组格式（自动迁移）；也兼容 `serverList` / `defaultServer` 驼峰写法。

### proxy.motd（服务器列表显示）

```json
{
  "lines": ["§a§lMinecraft Proxy", "§7Powered by Spring Boot"],
  "hoverLines": ["§6Welcome to our proxy!", "§7Online: §a%online%"],
  "fakePlayersEnabled": false,
  "fakePlayersMin": 10,
  "fakePlayersMax": 50,
  "fakePlayersIncrement": 1,
  "maxPlayers": 100,
  "versionName": "Minecraft 1.20.1",
  "protocolVersion": 763,
  "randomMotds": [],
  "rgbSupport": false
}
```

### proxy.maxPlayers

整数，默认 `100`。

### proxy.tablist（TabList 拦截）

```json
{
  "enabled": false,
  "header": ["§6§lNyanID 服务器群", "§7在线: §a%online%"],
  "footer": ["§7跨服代理 · §b/server 切换"],
  "prefix": "",
  "suffix": " §8[%server%]"
}
```

- 占位符：`%online%`、`%max%`、`%server%`。
- `prefix`/`suffix` 包裹 TabList 中每个玩家名（1.8–1.18.2 客户端）。

### proxy.firewall（连接防火墙）

```json
{
  "enabled": true,
  "maxConnectionsPerSecond": 5,
  "maxConcurrentPerIp": 12,
  "maxLoginAttemptsPerMinute": 20,
  "maxLoginFailuresPerMinute": 6,
  "banDurationSeconds": 600
}
```

- 每个 IP 的每秒新连接数、并发连接数、每分钟登录尝试/失败次数；超限后临时封禁 IP `banDurationSeconds` 秒。

### proxy.kick-message（普通踢出屏幕模板）

```json
{
  "enabled": true,
  "kick_message_base": "&c&lYou have been kicked from the proxy!\n&7Reason: &f$reason\n&7Kick ID: &f$kickId"
}
```

- `&` 颜色代码、`\n` 或 `|` 换行。
- 占位符：`$playerName`、`$reason`、`$kickId`。

### proxy.ban-message（封禁屏幕模板）

```json
{
  "enabled": true,
  "banned_message_base": "&5&l... \n&b&l»&f&lPlayer: &4$playerName\n&b&l»&f&lReason: &c&l$reason\n&b&l»&f&lBanID : &c&l$banId\n&b&l»&f&lExpireTime : &c&l$expireTime"
}
```

- 封禁的即时踢出画面与后续登录拦截共用同一模板，保证一致。
- 占位符：`$playerName`、`$reason`、`$banId`、`$expireTime`（永久封禁显示「永久」）。

> 迁移说明：旧版本把封禁模板（字段 `banned_message_base`）也放在 `proxy.kick-message` 下；升级后首次读取会自动迁移到 `proxy.ban-message`（并统一占位符为 `$playerName`/`$banId`/`$expireTime`），`proxy.kick-message` 则重置为新的踢出默认模板。

### proxy.online-mode

布尔，默认 `true`。`true` 时走加密 + Yggdrasil/Mojang 会话校验；`false` 时使用离线 UUID。

### proxy.ip-forward

布尔，默认 `true`。向后端握手附加 `host\0ip\0uuid\0propertiesJson`（后端需在 `spigot.yml` 开启 `bungeecord: true`）。

### proxy.name

代理显示名（品牌插件消息），默认 `NekoProxy`。

### proxy.forge-support

布尔，默认 `true`。是否启用 Forge (FML) 握手拦截。
